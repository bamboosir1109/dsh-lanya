# 组件集成与扩展

dsh-lanya 是面向 DeepSeek Harness 的 QQ 角色集成包，由 DSH 插件、Windows 配套服务和可选外部组件组成。同一主 LLM 结合人设、近期对话与记忆决定何时使用工具；平台连接、内容读取和本机执行分别接入。

## 当前接入能力

| 组件 | 支持的功能 | 接入条件与说明 |
|---|---|---|
| NapCatQQ / SnowLuma | 群聊、私聊、引用消息与图片、真实表情图及语音发送；共用后端选择与连接核验 | 二选一安装供应商程序，配置自己的账号与 OneBot v11。切换前核对已加载的传输与引用能力，见 [QQ 后端](QQ-BACKENDS.md) |
| dsh-bili-scroll 与内容工具 | 推荐、详情、分 P 与时间窗字幕、按需查看同 CID 抽帧；通知、评论上下文、评论、回复和 @ 管理员 | 外部插件与审定增量补丁需分别部署，内容读取依赖相应服务。评论、回复和提及默认关闭，由本机配置启用，见 [B 站能力](CAPABILITIES.md#b站内容与互动) |
| GPT-SoVITS | 同一主 LLM 选择语音内容，本地合成、WAV 校验，再按当前会话许可发送 | 自行部署本地引擎及参考素材；合成工具不自动发送、不切换云端引擎，见 [语音](VOICE.md) |
| memento 与本地记忆维护 | 短期线索、长期事实、可塑更正、主题与时间检索、压缩、版本历史及恢复 | 原生记忆插件与相应补丁需协调加载，按工作区和角色过滤后再检索，见 [记忆](MEMORY.md) |
| 日记与活动记录 | 来源事实底稿、主 LLM 第一人称日记、活动与互动结果、本地控制台读取 | 日记由实际自主机会审阅已有证据后写入；刷新页面不调用模型代写，见 [记忆与日记](MEMORY.md#每日第一人称日记) |
| 独立浏览器与 2048 | 读取实际截图，逐步浏览或操作游戏，保存活动证据 | 浏览器服务与依赖需配置；安装器附带 2048 页面，页面存在不等于已玩过，见 [本机能力](CAPABILITIES.md) |
| Android | 真实设备或模拟器截图、按截图操作、固定设备与截图版本校验 | 安装 ADB、模拟器或连接设备；模拟器需硬件虚拟化条件，见 [Android](ANDROID.md) |
| 本地控制台与费用 | 查看上述部件、活动、记忆、视频及互动记录和每日人民币费用估值 | 运行本库面板服务；费用还依赖成本来源与本机价表，估值不等于供应商账单，见 [安装](INSTALL.md)与[限制](LIMITATIONS.md) |

NapCatQQ 和 SnowLuma 是可替换的 QQ 平台后端，不是两个聊天模型。QQ 会话继续使用同一角色策略和自己的历史。B 站、TTS、记忆等组件由各自上游维护，本项目提供集成、执行保护、记录与控制台，不包含这些上游程序本体。

## 从基础组合开始

先按[安装手册](INSTALL.md)部署 DSH 插件和本机服务，选择 QQ 后端，再配置角色与记忆。按需要加入 B 站、语音或设备服务，在控制台核对实际加载状态，并用真实客户端验收对应动作。可以只启用自己需要的部分；没有配置的能力应保留不可用或未知状态。

## 扩展自己的能力

1. 通过 DSH 的插件与工具机制提供新工具，明确输入、输出和依赖。先验证只读能力或本地执行结果，避免把请求受理写成完成。
2. 在可信运行能力上下文中接入工具的真实可用状态与调用说明，供现有主 LLM 选择。参考 [CAPABILITIES](CAPABILITIES.md) 中的上下文和本机执行器边界；网页或消息正文不能覆盖可信工作区和配置。
3. 涉及 QQ 发送时沿用当前会话的决定与最终出口；其他平台写入实现自己的目标核验、结果记录和未知处理。新的工具不能绕过休息、静默、预算或已有权限。
4. 为实际协议、失败、并发与重复请求增加必要验证，再接入活动记录或控制台。部署代码、重载进程和真实平台验收分别记录，升级前保留本机原件。

这是现有插件、工具与本机服务的集成方式，不是任意插件的自动兼容层。新增后端或平台需要实现相应适配；外部插件版本升级也需重新核对审定补丁与实际加载状态。

## 展示与实际执行

B 站按取得的字幕、时间窗与画面说明内容覆盖，不宣称仅靠详情或局部画面完整看完。评论、回复和提及是否执行由主 LLM 与本机设置共同决定；接口接受、公开可见和对方收到提醒分别核对。语音合成完成也不等于 QQ 已收件。

公开 README、演示与截图使用示例数据。本机身份、账号凭据、对话、记忆和日记独立保存；提交新集成时不要把运行原件加入公开仓库。
