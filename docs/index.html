MODULAR CAPABILITIES, ONE CHARACTER

把需要的能力，接到同一个角色。

01 / QQ BACKENDS

NapCatQQ / SnowLuma

两种 QQ 接入后端选择其一，群聊、私聊和引用共用同一角色与会话策略。

02 / BILIBILI

B 站内容与互动

读取时间窗字幕、按需查看抽帧，由主 LLM 决定评论、回复或 @ 管理员。互动需本机启用。

03 / LOCAL VOICE

GPT-SoVITS 语音

连接本地引擎，校验合成音频后，再按当前会话许可发出可播放语音。

04 / PLASTIC MEMORY

可塑记忆与日记

短期上下文、长期事实、更正、压缩、主题时间检索与来源可回看的第一人称日记。

05 / EXPRESSION

真实表情与接话

按标签选择真实表情，可只发图，一轮最多一张；结合最新话题判断回应或安静。

06 / AUTONOMY

主 LLM 自主决策

人设、近期对话与记忆共同提供上下文，选择活动、分享或休息，遵守预算与联系间隔。

07 / LOCAL TOOLS

浏览器、游戏与设备

按需接入独立浏览器、2048 与 Android 截图操作；设备和依赖就绪后再执行。

08 / EXTENSIONS

按需集成，继续扩展

沿用 DSH 插件工具与本机执行器，复用可信能力上下文、会话边界和活动记录。

09 / LOCAL CONSOLE

一处看见运行过程

连接、部件、视频与回复、活动、记忆日记和每日人民币估值集中查看，未知状态保留。

外部组件按各自手册安装。字幕和局部画面不代表完整播放；平台接口接受不代表公开可见。查看组件接入表与扩展步骤 ↗
