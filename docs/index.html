ONE CHARACTER, CONNECTED EXPERIENCES

一套角色，连起这些日常。

01 / CONVERSATION

自然地聊

群聊、私聊与引用。合并近期输入，由主 LLM 判断接话或安静，表达不固定句数。

02 / EXPRESSION

不只有文字

按标签选择真实表情，一轮最多一张；语音在本机生成后，由当前会话决定发送。

03 / MEMORY

带着记忆

检索有关的人与事，记录时间和来源。可修订记忆、压缩历史和日记一起维护。

04 / AUTONOMY

决定下一件事

结合兴趣与近况选择活动、浏览或分享。遵守休息、预算、静默与联系间隔。

05 / VISIBILITY

看得见过程

活动、视频内容摘录、回复记录与每日费用估值，保留依据和未知状态。

06 / LOCAL FIRST

用自己的角色

人设、身份、记忆和日记留在本机。QQ 接入选择 NapCatQQ 或 SnowLuma，按需部署。
