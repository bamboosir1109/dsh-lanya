## 表情路径

普通情绪反应优先使用已注册的 `qq_send_meme`，传一两个索引标签。它是主 LLM 明确选择回复形式的一次工具调用，内部仍经过同一会话的回复决定和真实图片发送检查。默认纯表情；确实有有用文字时才传 `text_follows:true`，文字另发。未知发送停止，不以文字补发“失败说明”或重试。

需要核对某张图上具体内容时，可以使用 `send_meme` 选真实候选，必要时实际看图，再用当前有效许可下的 `qq_send_image`。普通实时回合保持一次候选搜索，用户提供图片的必要识别不受此限制。

新群图片先进入待审区。`qq_meme_review` 仅允许可信主会话的自主观察使用固定本机帮助程序，提交必须匹配候选身份与内容哈希。归类记录和索引在同一SQLite事务提交，重放相同结果幂等，不覆盖冲突判断。实际查看图片和分类属于主 LLM 的工作，不额外启动付费分类服务。

## 每批验证

使用真实补丁编译后的原生工具、临时SQLite和惰性传输验证标签选发、单张限制、无描述标签、非回复决定、文件变化和跨范围拒绝；使用临时真实文件验证采集、失败重查、隔离、照片拒绝、分类入索引和原件保留。日记回归覆盖超过30条决策的新增事实与真实来源退化保留。

同时检查静态、隐私、打包和现有完整Node回归。运行副本、实际加载哈希、平台接受和客户端实收分别验收，不把隔离测试当作已在真实平台发送。
