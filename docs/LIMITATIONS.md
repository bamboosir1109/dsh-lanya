# 已知限制

本文区分程序当前提供的能力与需要现场验证的部分。历史 DEVLOG 的待办可能已被后续代码修复，不直接当作当前故障清单。

## 安装不等于整套环境已经可用

仓库不提供 DSH 本体、NapCat/QQ、GPT-SoVITS 或其他插件。B 站、独立浏览器、图像处理和记忆页各有自己的依赖。缺少某一项时，相关脚本可能跳过或只显示空状态；应查看实际日志与输出，不能只看 `enabled`。

安装器只部署文件，不修改 QQ 登录、不写账号凭证、不注册计划任务、不自动部署到另一台机器。管理员计划任务、NapCat 桌面注入和账号登录都需要按本机环境处理。

## 仍有默认端口与旧名称

前端当前仍使用默认 API 端口 19389，部分功能脚本保留默认端口或旧安装路径。集中配置读取已覆盖核心目录解析，但更改所有端口、切换 DSH profile、改外部工具安装位置后，仍需逐项验证对应调用方。

新文件使用 `lanya-*`；历史 `dafeiyu-*` 名称只在部分入口有兼容。已有旧配置先按[安装说明](INSTALL.md)迁移，不能假设所有脚本会自动识别所有历史命名。

## 自主活动与费用

`mind.py` 依赖 DSH agent、活动依赖和本机预算状态。它保留计划并决定下一次活动时间，但这不能保证每项计划都能成功完成；要看实际文件、日志和外部返回值。

零花钱默认只约束自主活动，聊天属于另一个费用范围。它不是账户级总消费硬限制，也不阻止其他程序或直接 API 调用产生费用。

## QQ 与语音

NapCat 可用性受 QQ 登录、注入状态和协议兼容影响。QQ 签名读取接口曾返回不支持，页面可能只能展示本地记下的最近一次值。

统一许可与分段限制需要审定的OneBot 0.8.1补丁，外部插件升级可能覆盖；修改后要重启宿主。新版主agent使用`qq_synthesize_voice`合成本地文件，再以当前reply许可调用`qq_send_voice({path: ready.file})`；本地ready不代表QQ送达。旧独立语音消费者在unified暂停，积压需单独核对，不能把暂停当作完成，见[语音](VOICE.md)。

每日提醒默认在到期后 5 分钟内认领，条目 `dailyGraceMinutes` 可设为 0–60。已经持久认领的 occurrence 保留原日期和身份；主模型约定的复查不会因越过窗口或午夜而丢失。完全未认领的旧提醒不无限追发；unknown 不自动重试，idle 不强求回复。

## B 站

登录凭证由使用者本机保存，扫码状态可能有短暂延迟。发评论、删自己的评论、关注等动作涉及真实账号，不适合作为默认测试。

当前代码包含自己的评论删除入口，但是否成功取决于登录状态、权限与第三方接口兼容；不能删别人的评论。视频上传尚未接入。只删本地判重记录不会自动删除站上的评论，也可能使之后重复处理同一内容。

“真看视频”通过下载视频、ffmpeg 抽帧和拼图提供画面信息；无权限、下载失败或缺依赖时应报告失败，不能把拿到标题当成已经看过全部视频。

源码中的娱乐和通知观察交给同一主agent；旧scroll安装还需部署审定的2.2.0主agent补丁，才会关闭其独立headless定时、DM和手动入口。新增私信工具按实际session/callId持久防重，新的callId表示新动作；旧评论工具未纳入该账本，不能宣称全平台exactly-once。表情分类同样观察现有候选；新群图片自动采集尚未整体迁移，不能将“已提交分类观察”当作已收集或已看过图片。

## 真实 Android

手机页已改为真实设备截图与单步动作协议，设备 offline、worker 缺失、PNG 损坏、画面过期或 serial 不符时均不允许操作。模拟器安装、AVD 创建、硬件加速、系统启动、ADB 在线、截图和动作成功是不同阶段，必须分别验收。推荐的加速路径可能仍需 BIOS SVM、WHPX 或重启前置；官方另有不受支持且很慢的软件模拟入口，硬件加速失败不等于软件模式不存在，单次软件模式崩溃也不代表所有组合都不可用。两条路径都不能由网页或离线测试代替实际开机验收，见 [ANDROID](ANDROID.md)。

## 控制台与检查工具

面板是本机管理入口，没有完善的多用户鉴权与公网访问控制；不要直接开放到公网。部分按钮有文件写入、删除或外部发布副作用，浏览器全按钮测试需要隔离环境。

静态检查捕获常见代码形状，不证明每个条件分支都执行过。隐私扫描是规则匹配，不能识别全部私人内容。真实服务是否健康需要结合端口、进程、日志、数据更新时间及预期副作用。

## 当前验证范围

本轮维护以离线回归、临时目录安装与打包清单检查为主；没有凭此宣称所有真实 QQ、B 站、TTS、浏览器及 GUI 自动化链路已经重新验收。生产部署后的结果应单独记录在本机运维文档。

新 OneBot 补丁停止未来的无范围档案注入；旧 DSH 会话已写入的上下文仍在。启用范围保护时要保留原会话证据并明确选择干净会话，不能说修补代码就已经清除了历史内容。
