你要帮我把一批表情包按**情绪和使用场景**分类。

这些图是从 QQ 群里收回来的。我要的不是"是不是表情包"，而是：
**如果我要在聊天里用这张图，我是在什么情绪、什么场景下用？**

**先逐张看图**（用你的读图能力，别靠猜文件名），然后给每张一个分类。

---

## 分类只能从下面这些里选，别自己造

| 标签 | 什么时候用 |
|---|---|
| `happy` | 开心、笑、撒花、被夸了 |
| `sad` | 难过、委屈、想哭、求安慰 |
| `angry` | 生气、吼人、摔东西、瞪人 |
| `speechless` | 无语、白眼、扶额、"你认真的吗" |
| `shy` | 害羞、脸红、不好意思、被撩到 |
| `surprise` | 惊讶、震惊、张大嘴、瞳孔地震 |
| `lazy` | 躺着、瘫着、不想动、摆烂 |
| `sleepy` | 困、晚安、打哈欠、睡着了 |
| `hungry` | 饿、干饭、吃东西、馋 |
| `work` | 上班、加班、写作业、赶工 |
| `money` | 要钱、吃土、破产、红包 |
| `cheer` | 加油、打气、冲冲冲、支棱起来 |
| `thanks` | 谢谢、鞠躬、抱拳 |
| `refuse` | 拒绝、不要、达咩、摆手 |
| `confused` | 问号、懵、思考、不理解 |
| `cute` | 卖萌、撒娇、抱抱、比心 |
| `cool` | 装酷、墨镜、得意、嚣张 |
| `pray` | 祈祷、求求了、保佑 |
| `scared` | 害怕、瑟瑟发抖、溜了 |
| `other` | 上面都不像——**能当表情包但归不了类** |
| `notmeme` | **不是表情包**（新闻截图、聊天记录、长文截图、照片、商品图、二维码） |

---

## 判断要点

1. **看这张图表达什么情绪**，不是看它画的是什么。一只猫在哭 → `sad`，不是"猫"。
2. **带字的图优先看字**。字写的"我裂开了"→ `speechless`；"晚安"→ `sleepy`。
3. **归到使用场景，不是归到内容**。熊猫头竖大拇指 → `cheer` 或 `thanks`，看手势语气。
4. **拿不准就 `other`**，别硬塞。**新闻/截图一律 `notmeme`。**
