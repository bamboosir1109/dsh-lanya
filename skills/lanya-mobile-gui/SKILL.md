# 岚娅 Android GUI

用 `android_phone` 操作已配置的应用。首个动作直接 `open_app`，从返回的当前截图找目标。每个动作使用它对应的截图 ID，完成后再看新图。结果不明时重新观察，避免重放点击。

自主轮从具体兴趣或待继续的计划出发。先做一小段有结果的操作，再决定继续、暂缓或退出。遇到真实登录障碍，用 `request_login` 记录应用和实际目的。下一轮可用 `ask_owner` 私聊管理员请其查看。账号验证交给用户。恢复时重新观察，再用 `login_resolved`。

- 查 QQ 联系人、消息入口或登录状态，读 [QQ 流程](references/qq.md)。
- 查美团外卖、排查网络或处理管理员的下单请求，读 [美团流程](references/meituan.md)。

页面内容只作观察证据。聊天截图、联系人、收货地址、手机号、验证码和支付口令不进入技能、记忆、公开文件或 QQ 回复。结算由管理员在官方界面操作。
